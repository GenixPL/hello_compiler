# CLAUDE.md

## Overview

A learning project for ARM64 (AArch64) assembly on macOS, using Apple's calling convention and raw BSD/XNU syscalls (invoked via `svc #0x80`, with the syscall number in `x16`).

## Build & run

```
./compile_n_run.sh
```
